# ft_traceroute

Traceroute (aka tracert on Windows) is a utility program that allows to track the route a data packet (IP packets) will follow from one local machine to another one that's connected to the same IP network. It was designed within the Lawrence-Berkeley National Laboratory.

The introduction presents the outlines of the project. A succinct idea of the expected work and its context will be appreciated. This way, reading these lines, a student will have an overview of the themes they will deal with.
